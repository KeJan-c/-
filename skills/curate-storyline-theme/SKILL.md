# 故事线及主题包装提炼

将项目事实转化为可理解、有辨识度、可落实的主题与叙事。复用判断方法，不复用其他项目的物象、名称、节点顺序和视觉风格。

## 工作边界

- 先读取已有资料、有效要求和已认可成果。保留成立的内容，只调整有问题的部分。
- 按当前任务选择完整推导、局部命名或逻辑复核。用户只改一个标题时，不重做全部策划。
- 缺少决定性信息时，询问最少必要问题；其余部分继续推进。将假设与已确认事实分开。
- 默认在对话中交付。未经请求，不改写项目文件、不发布内容。

## 推导方法

### 1 明确核心命题

回答：项目最值得讲什么，观众为什么需要了解，看完应形成什么认识。用一句普通语言概括，暂不使用比喻和口号。

### 2 建立叙事骨架

识别实际内容关系，选择时间演进、问题与回应、过程追踪、系统关系、对比讨论或人物经历等方式。可组合，但需有清楚主线。

先用一段话讲清故事，确认主体、因果、顺序和结果。不要预设固定的节点数量或“背景—行动—成果—未来”结构。并列内容不强行写成递进。

### 3 寻找包装切入点

从核心问题、代表成果、人物事件、行业过程、材料结构、地方文化、场所记忆或观众经验中寻找方向。

包装可以是物象，也可以是观点、问题或行动。不得为了形式强加比喻。需要多个方向时，提出实质不同的概念，不围绕同一意思反复替换近义词。

### 4 验证内容关联

每个方向说明：事实依据 → 提取的特征 → 对应内容 → 展示可能。

- 地方或行业关联必须具体，避免仅以普遍适用的特征宣称独特性。
- 谐音、形似可以辅助表达，不能独自承担整个概念。
- 区分事实依据与创作联想；涉及历史、字源、技术等不确定事实时查证，不能为包装编造依据。
- 需要多次抽象跳转才能解释的概念，应简化或放弃。只适合局部的概念，可降为展项包装。

### 5 提炼主题名称

先定概念，再命名。字数和修辞不限，以自然、准确、易记为准。通过词义、节奏和具体形象提升文学性，不以生僻词、生造词或抽象词堆叠制造高级感。

检查六项：

| 标准 | 判断问题 |
|---|---|
| 准确 | 是否抓住核心内容，而非只描述形式？ |
| 关联 | 能否用一句话解释与项目的关系？ |
| 理解 | 受众能否理解，是否会误判展览类型？ |
| 辨识 | 换成其他项目后，是否仍能原样使用？ |
| 得体 | 语气、情绪和文学程度是否符合受众与项目性质？ |
| 延展 | 能否支撑节点、视觉及重点展项？ |

积极、庄重、轻松或批判等表达取向依据项目要求确定，不将某一项目的禁用词普遍化。比较候选时给出明确推荐及具体不足；无须编造精确评分。

### 6 包装故事节点

先确定各段任务，再拟标题。每段说明：回答什么问题、使用哪些内容、形成什么认识、如何进入下一段。

节点名称保持相近的表达尺度和语言风格；一致句式是可选方法，不为整齐牺牲原意。故事节点与物理展区不必一一对应。

### 7 建立视觉与展项关联

为需要视觉表达的节点设置具体锚点，并说明形象之间的关系。可采用同一对象的阶段变化、系统组成、尺度变化或视角转换，不拼接互不相关的配图，也不强制所有节点使用同一物象。

重点展项按“内容特征 → 形式 → 观众体验 → 获得的认识”推导。主题应体现于形态、材料、过程或互动机制，不仅是重复文字、颜色和图案。

已有空间方案优先检查可利用部分，但不为少改图而扭曲内容。参考图、设计设想与确定方案应明确区分。

## 默认交付

根据用户所处阶段选用以下成果，不机械输出全部过程：

1. **主题说明**：名称、核心命题、概念依据及简短释义。
2. **故事线表**：节点名称、内容解释、衔接关系、视觉锚点。
3. **转化说明**：主题在空间或重点展项中的具体表现。

需要候选比较时，先列概念差异，再给推荐；已有主题获认可时，直接深化，不重新发散。说明文字清晰、专业、简洁，使用高中至本科读者可以准确理解的语言。每段承担一个任务，不重复赞美概念或追加空泛口号。

## 交付检查

- 去掉包装词，故事是否成立？加入包装后，是否更容易理解与记忆？
- 主题能否覆盖主线，关联是否足够直接？
- 节点是否有缺环、倒置、重复回退或范围重叠？
- 名称、解释、视觉与展项是否表达一致？
- 是否为迁就名称而改变事实、顺序或已确认要求？
- 能否向受众说明重点展项具体讲什么、怎样体验？

概念牵强，返回关联验证；结构混乱，返回叙事骨架；仅语言生硬，再调整名称。不要用改名掩盖内容问题。
