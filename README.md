# Codex 策展技能

## 故事线及主题包装提炼

从项目事实提炼展览主题、名称和故事线，建立视觉锚点与重点展项的对应关系。支持完整概念推导、局部命名和已有方案的逻辑复核。

- 技能说明：[SKILL.md](skills/curate-storyline-theme/SKILL.md)
- 技能标识：`curate-storyline-theme`
- 安装：将 `skills/curate-storyline-theme` 文件夹复制到 `~/.codex/skills/`。
- 调用：`使用 $curate-storyline-theme，根据本项目资料提炼主题包装与故事线。`

方法不预设行业、地域意象、主题字数或故事节点数量；根据各项目的事实、受众和实施条件调整。
